# PTC Social Dashboard

Live overview of PTC uploads and channel performance on Instagram, TikTok and YouTube.

View it at **https://pjd-creator.github.io/ptc-dashboard/**

- `index.html` — the dashboard page
- `data.json` — the numbers, refreshed every hour from Metricool
- `scripts/build_data.py` — turns Metricool's answers into `data.json`
